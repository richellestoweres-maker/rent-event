On an iPhone, read this first

  1. Apple only allows notifications from a website if it has been added to the Home Screen. Opening this page in Safari will not work, no matter how many times you tap Enable.
  2. In Safari, tap the Share button, then Add to Home Screen.
  3. Close Safari. Open RentEvent from the new Home Screen icon.
  4. Come back to this page from inside that app and tap Enable Notifications.
